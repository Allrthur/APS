# Balanceamento de Classes com Seleção de Paráfrases para Classificação Binária de Textos

## Pré requisitos:

- Instale as bibliotecas necessárias com  ```pip install -r requirements.txt ```
- Caso necessário, instale o PREDATOR através do github: https://github.com/hugoabonizio/predator

## Ecexutando a classificação:
Use o arquivo quickstart.sh como exemplo para rodar a classificação.
 
## Executando a geração de paráfrases:
Execute o arquivo llm_paraphraing.py através do comando: ```python llm_paraphrasing.py```
